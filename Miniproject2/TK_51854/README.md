# Vehicle Config Builder with Decorators

## Overview
This project demonstrates the use of the **Decorator Design Pattern** to dynamically add features to vehicles.

## Features
- Add Sunroof
- Add Navigation System
- Add Leather Seats

## Benefits
- Open/Closed Principle
- Flexible feature addition
- Avoids large inheritance trees

## How to Run
python main.py

## Sample Output
Displays step-by-step car configuration with cost updates.
